# Clipping to Project/Area Notes (not standalone references)

The default destination for a clipping is a standalone Notes row. Some clippings belong to a
Project or Area instead, when they directly inform or shape that work.

**Decision test:** *"Would I file this under a project/area if I were retrieving it later while
working on that thing?"*

**Examples:**
- Video essay on content creation philosophy -> a Notes row related to the Work-Of-Ekajaya area
- Article on a skincare routine -> a Notes row related to the Health-and-Fitness area
- Tech tutorial -> a standalone Notes row (pure reference)

**Key difference:** a project/area note gets a "## My Take" section connecting the content to the
work; a standalone reference stays as reference. In Notion the difference is the `Project` or
`Area` relation on the row (one side only) - the row type stays `Note`/`Reference`.
